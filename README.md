# Casa Shine — Casablanca car wash website

Multi-page static site with smooth scrolling (Lenis), scroll animations (GSAP),
3D tilt cards. No build step needed.

## Edit content
Everything (phone, WhatsApp, address, prices, services, team, reviews, articles)
is in **assets/js/data.js**.

## Pages
index, about, services, service (?s=slug), pricing, team, blog, post (?p=slug), contact, 404.
Page shells are generated by `bash tools/build-pages.sh`.

## Deploy
Vercel, framework preset "Other". `vercel.json` enables clean URLs.
